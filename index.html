Legally Required Finished Product Testing (Table 7) — cfu/g
How to read n / c / m / M:
n = number of sample units taken (always 5 here)  ·  c = max units allowed to fall between m and M before batch fails  ·  m = standard/target — aim to be below this  ·  M = absolute ceiling — ANY unit above M = automatic fail regardless of others.

Example — Meat Preparations E. coli (the 5000 rule): Take 5 units. Up to 2 may fall between 500–5000 cfu/g (the amber zone). If 3+ fall in that zone OR any single unit exceeds 5000 → batch fails outright. All 5 under 500 = compliant. The "limit" people quote as 5000 is M — the ceiling. The real target (m) is 500.

Control Swabs & Control Plates
Control swabs: Must NOT be used to sample. Label, tape up, return with sample swabs. They check sterility, swab integrity, and sampler technique.
Control plates: Must NOT be opened. Label, tape up, return with sample plates.
Both must always be included with submissions.
About the MIMS Save File: The MIMS_SAVE_FILE.xls (Submission sheet, 37 columns) is the master submission database used by SampleHub. Every sample entry maps to a MIMS seed row which determines SUITE, PRICE, EOL, SHIFT, and other locked fields. The columns below are exactly what appears in MIMS exports and result returns.
